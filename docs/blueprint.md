# **App Name**: Cluck Rebellion

## Core Features:

- Batch Tracking: Add and track new egg batches with details on quantity, date laid, and hen house.
- Financial Records: Record all sales and expenses, linking transactions to specific batches.
- Dashboard Generation: Generate customizable dashboards presenting inventory levels, sales trends, and profitability metrics, incorporating an LLM 'tool' for intelligent insights.
- Spreadsheet Sync: Seamlessly synchronize all data with an existing Google Spreadsheet for backup and advanced analysis.

## Style Guidelines:

- Primary color: Deep red (#8B0000) to evoke the boldness and rebelliousness of the theme. The hue is inspired by the 'rebel theme' concept from the user prompt, but it avoids cliches like black which could suggest morbidity instead of revolution. As well, this saturated tone can pair nicely with the background and accent colors.
- Background color: Charcoal gray (#36454F), desaturated to maintain focus on the content and create contrast against the bright elements.
- Accent color: Industrial metallic (#B8860B), an analogous tone of brownish gold, to highlight key actions and metrics. It provides a subtle yet visible contrast, drawing attention without overwhelming the deep reds.
- Body and headline font: 'Inter' (sans-serif) for a modern, machined look appropriate to an industrial context.
- Use stark, simple icons in the metallic accent color to represent batches, sales, and data points.
- A modular, grid-based layout to maximize data presentation and ease of navigation.
- Subtle transitions and animations to guide users through data exploration without distracting from the metrics.
